Memory is the live runtime source. Redis is the persisted operational snapshot used for bootstrap and some background flows.

Process

1. Source fetchers update in-memory caches first.
2. The same flow then persists a best-effort snapshot to Redis.
3. On restart, the server hydrates memory from Redis before live refreshes run.
4. Divergence can happen if Redis writes fail, expire, lag, or a different process writes newer data.
